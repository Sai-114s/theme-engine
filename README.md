# Theme Engine

A lightweight theme playground for adjusting design tokens (colors, spacing, radius, shadows) in real time.

## Features
- Live theme controls for CSS variables
- Dark and light mode toggle
- Random theme generator
- Export current color tokens to clipboard

## Getting Started
1. Open `index.html` in your browser.
2. Use the sidebar controls to adjust the theme.
3. Click "Copy CSS Variables" to export the current colors.

## Project Structure
- `index.html` - UI and layout
- `portfolio.css` - Styles and design tokens
- `portfolio.js` - Theme controls and interactions

## Notes
This is a static front-end project and does not require a build step.
